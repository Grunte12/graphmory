## Failures repaired before publication

Read-only Luna review found that stale-language and TENSION checks scanned raw Markdown even though link-history analysis already masked code/comments. Reusing the existing mask removes the concrete false positives and prevents code-only decision-path text from excusing real conflict metadata. New regressions retain genuine stale/conflicting prose findings. The targeted lifecycle-context suite passes 10/10.

Publication screening found two absolute user-vault paths in historical reports. They were replaced with `<user-vault>` without changing the recorded outcomes. Python bytecode/cache paths are now ignored. A prior package audit found two missing linked reports in the explicit allowlist; that failed archive and repair record remain preserved separately.
