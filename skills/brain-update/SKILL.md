# Brain Update

This is a lead-agent write workflow. Do not delegate it to a read-only curator
or intake reviewer.

## Preconditions

Require a complete Memory Patch or Learning Packet with claim, rationale,
scope, provenance, confidence, lifecycle, revalidation trigger, and required
approval. Never promote an Evidence Digest, transcript, hook event, embedding,
or graph edge directly.

## Apply

1. Recall the project home and strongest nearby canonical note.
2. Verify provenance and apply the significance gate.
3. Merge compatible meaning into the strongest atomic note; create a new note
   only for a distinct durable concept.
4. Preserve active disagreement as `TENSION`; never silently overwrite it.
5. Preserve scope, confidence, lifecycle, revalidation, and supersession links.
6. Link from the project map and only useful related notes.
7. Return `APPLIED`, `TENSION`, or `BLOCKED` with changed paths and checks.

Never save secrets, full transcripts, raw logs, or unsupported speculation.
Never auto-push; publishing requires explicit user approval.
